# demos

Reference apps built with Streamlit. Each folder is a self-contained app with
its own `requirements.txt`. All data is synthetic.

| App | Use case |
| --- | --- |
| [`bi-dashboard`](bi-dashboard) | Dashboards: Nimbus BI, a revenue dashboard with layout-first loading, filters in the URL, certified metrics, drill-down drawers, and an Ask AI drawer that answers from the same data |
| [`forecasting-app`](forecasting-app) | Forecasting apps: Cairn Demand lab, a Monte Carlo demand and pricing simulator with what-if levers |
| [`workflow-app`](workflow-app) | Workflow apps: Cairn Reorder desk, a review queue where planners approve the purchase orders an AI agent proposes |
| [`agent-app`](agent-app) | AI chat and agent apps: Cairn Analyst, a chat-based analyst that shows its steps, streams its answers, opens its analysis in a canvas, and drafts orders people approve |
