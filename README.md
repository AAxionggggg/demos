# demos

Reference apps built with Streamlit. Each folder is a self-contained app with
its own `requirements.txt`. All data is synthetic.

| App | Use case |
| --- | --- |
| [`bi-dashboard`](bi-dashboard) | Advanced dashboards: Nimbus BI, a revenue dashboard with layout-first loading, filters in the URL, certified metrics, drill-down drawers, and an Ask AI drawer that answers from the same data |
| [`apps-that-compute`](apps-that-compute) | Apps that compute: Cairn Demand lab, a Monte Carlo demand and pricing simulator with what-if levers |
| [`apps-that-act`](apps-that-act) | Apps that act: Cairn Reorder desk, a review queue where planners approve the purchase orders an AI agent proposes |
| [`agent-app`](agent-app) | AI chat and agent apps: Cairn Analyst, a chat-based analyst that shows its steps, streams its answers, opens its analysis in a canvas, and drafts orders people approve |
